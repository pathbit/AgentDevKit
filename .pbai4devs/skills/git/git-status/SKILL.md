# git-status

Mostre branch, alterações preparadas e não preparadas, arquivos não rastreados e
divergência do upstream. Execute a consulta com `GIT_OPTIONAL_LOCKS=0` no
ambiente do subprocesso para evitar atualizar o índice; não altere arquivos.
