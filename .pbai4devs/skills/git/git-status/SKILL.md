# git-status

Mostre branch, alterações preparadas e não preparadas, arquivos não rastreados e
divergência do upstream. Use `GIT_OPTIONAL_LOCKS=0` nas consultas, sem presumir
que isso garanta a preservação exata dos bytes do índice. Se ela for exigida,
use apenas um método comprovadamente seguro para o repositório ou informe a
limitação.
