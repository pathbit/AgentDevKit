# git-push

Confira branch, upstream, commits a publicar, identidades e mensagens, além das
verificações. Envie somente tarefas completas e verificadas, respeitando
`.pbai4devs/rules/git/RULE.md` e as proteções do remoto. Se houver autoria,
coautoria ou identificação de agente, informe e não publique esses commits.
Não use push forçado; se houver divergência ou erro, informe e preserve o trabalho.
