# git-pull

Confira branch, upstream, alterações locais e divergência; busque e integre o
remoto sem descartar trabalho ou reescrever histórico. Se for necessário um
commit de merge, confira antes as identidades efetivas e siga
`.pbai4devs/rules/git/RULE.md`. Se houver conflito, preserve o estado e resolva-o
somente dentro do escopo autorizado.
