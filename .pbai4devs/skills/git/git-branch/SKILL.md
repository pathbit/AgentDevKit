# git-branch

Confira branch atual, worktrees e alterações locais. Crie ou troque a branch
solicitada sem sobrescrever ou descartar trabalho; siga o fluxo de specs em
[implementar-spec](../../specs/implementar-spec/SKILL.md), incluindo a escolha
da branch de base conforme o projeto existente.
