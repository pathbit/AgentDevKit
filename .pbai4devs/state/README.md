# Estado

`agentdevkit.json` e `derived.json` registram seleção, propriedade e arquivos
gerados nesta máquina. São locais e ignorados; não os edite manualmente.

As decisões de produto em `configuracao/ESTADO.md`, quando criadas pelo fluxo
do projeto, são fontes compartilhadas e podem ser versionadas. Comece pelo
[modelo de configuração](../templates/configuracao/TEMPLATE.md).
