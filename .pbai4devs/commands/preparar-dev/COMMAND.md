# Preparar desenvolvimento

Entrada: objetivo ou erro observado, se houver. Pré-requisito: projeto existente.

Siga [preparar-dev](../../skills/projeto/preparar-dev/SKILL.md), começando pelo
[diagnóstico](../diagnosticar/COMMAND.md). Reúna dúvidas antes das alterações;
reutilize os scripts e ferramentas indicados pela skill.

Saída: ambiente verificado, comandos de execução, URL e pendências; evidências
locais em `.agent-tests/`. Não reinicie o planejamento de produto.
