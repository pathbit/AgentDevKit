# Status do roadmap

Entrada: nenhuma. Pré-requisito: configuração com o caminho do roadmap.

Use [gerenciar-roadmap](../../skills/specs/gerenciar-roadmap/SKILL.md) em modo
somente leitura. Se faltar planejamento, informe a próxima etapa do fluxo.

Saída: status das releases e specs, pendências e próxima entrega.
