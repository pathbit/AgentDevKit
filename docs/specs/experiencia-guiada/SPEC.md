# Experiência guiada no terminal

Ao adotar o kit, a equipe precisa saber o que verificar e qual recurso usar a
seguir. Em um projeto existente, ela também precisa aproveitar os documentos
que já orientam o trabalho.

## Critérios de aceite

- **AC-001** A CLI encadeia instalação, diagnóstico, verificação da
  sincronização e orientação. Divergências permitem revisar o plano antes de
  aplicar. A intenção de execução de uma aplicação mantém o foco no ambiente.
- **AC-002** A consulta opcional de integrações funciona antes e depois da
  instalação. Mostra caminhos reconhecidos e orienta seu uso sem ler o
  conteúdo dos artefatos, seguir links simbólicos ou executá-los.
- **AC-003** O README distribuído pelo npm e o guia no GitHub descrevem quando
  adotar o kit, como começar e quando consultar BMad, OpenSpec, GitHub Spec Kit,
  Tech Leads Club ou Dotcontext.
- **AC-004** O pacote passa pelas matrizes de compatibilidade e atualização.
  A validação em uma cópia do Talquee compara arquivos próprios e índice Git.
