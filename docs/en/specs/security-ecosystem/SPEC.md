# Local security ecosystem

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

## Objective

Install security procedures with the kit and connect skills, commands, agents,
rules, scripts and tools in complete streams. Document the responsibility of
each feature and use open source local analysis without account or mandatory
payment. Update the talquee-ai-router by npm to 0.0.10 preserving its content
and configuration.

## Contract

- Skills explain procedures; agents take on a task and your delivery.
- Commands organize entries and steps; scripts perform deterministic actions.
- Rules guide contexts; tools provide local capabilities.
- The facility includes security sources and notes from the chosen customers.
- Scanners are explicitly installed without starting services.
- Public downloads are separated from offline analysis, with pins and integrity.
- Absence of tool, basis or proof never equals an approved audit.
- Secrets, code and reports remain local.
- Scanners do not replace authorization tests, isolation and business rules.
- Preserve history and customizations in both repositories.
- Distribute new resources on 0.0.11, keeping the router fixed at 0.0.10.

## Acceptance criteria

| ID | Observable result |
| --- | --- |
| AC-001 | Installation includes skills, rules, commands and security profiles. |
| AC-002 | Docs explain connected components and flows, with cases of use. |
| AC-003 | Three scanners OSS install, update and check the local pins. |
| AC-004 | Offline audit detects unsafe fixtures and differentiates faults. |
| AC-005 | Reports don't expose secrets and remain ignored by Git. |
| AC-006 | Curadoria records sources, licenses, limits and corrections of the article. |
| AC-007 | Router in 0.0.10 preserves files, index, language and customers. |
| AC-008 | Returns, real package, mirrors and independent review pass. |

## Validation

Check resource creation and discovery in new and existing installations. Run
real scanners against secure and unsafe local cases, with controlled databases
and no calls to analytics services. Test downloads, hashes, links, rollback,
missing data, scanner errors and written outputs. Compare router snapshots
before and after npm update.

Test code is versioned; bases, binaries, reports and snapshots stay in
`.agent-tests/`, `.local/` or `tmp/`, ignored by Git.
