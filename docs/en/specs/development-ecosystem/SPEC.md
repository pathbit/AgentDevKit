# Development ecosystem

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

The kit guides teams and agents in architecture, backend, frontend, QA,
security, review and performance without determining the technology of the
project. The features are instructions: their existence does not execute agents
or tools.

## Acceptance criteria

- AC-001: Skills and specialized profiles are discovered by selected customers
  and point to shared sources.
- AC-002: The flow distributes independent tasks when there are subagents
  allowed and available, defines responsibilities and integrates the results.
  Without delegation or independent review, it informs the limitation.
- AC-003: The guidelines select real evidence by risk and criterion, including
  failures, accessibility and adverse analysis when applicable; distinguish
  observed results and unexecuted checks.
- AC-004: Installation preserves settings, existing content, Git index and the
  `.gitignore` the root of the project.
- AC-005: Documentation and catalogs explain the use of resources and their
  limits; source checks, integration and distribution are executed.
- AC-006: OpenCode V2 review profile denies editing, shell and delegation on
  generated frontmatter.

## Verification

Run the integration tests and the full local pipeline. Check the generated
adapters, content preservation and independent review result. Register proofs
and to-dos according to the delivery gate.
