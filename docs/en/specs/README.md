  by module and evidence in the code and tests.

Each increment links requirements, criteria, tests and local evidence.
[roadmap](../product/roadmap.md) distinguishes published releases from pending
work. Specs record the contract of the time, including historical patterns of
customer selection and Git exclusion. [installation](../guides/installation.md)
e [CLI](../guides/cli.md) document the current behavior. [specs
control](../product/spec-audit.md) records the criteria whose review and
validation are pending.

These are the increments of AgentDevKit itself. To create a project spec, follow
the [flow](../guides/workflow.md) and use the [Shared
templates](../kit/templates/README.md).
