# Local security

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

The kit installs skills, rules, commands and profiles to review security.
Scanners require explicit preparation; no audit or application starts in the
background just because the instruction files have been installed.

O [operational guide][guide] it explains preparation of tools, offline
databases, report and screening, in addition to manual tests of authorization,
data isolation, input and abuse.

- [Prepare security][prepare]: install and check local scanners.
- [Audit Security][audit]: analyze the authorized target and interpret signals.
- [Review authorisation][authorization]: test identity and access by resource.
- [Model Threats][threats]: to anticipate the risks of borders of trust.
- [Curatorship](security-references.md): sources, licenses and evaluated tools.

Use the [ecosystem map](resources.md) to understand how profiles, skills,
commands, rules and scripts connect. `.agent-tests/`; scanners alone do not
approve the safety of a product.
