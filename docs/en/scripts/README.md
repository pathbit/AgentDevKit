# Repository automations

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Use root npm commands. [release](release/README.md) contains verification,
packaging and product publication. `npm run verify` performs the full profile;
`npm run build` It generates local tarball, without publishing.

The automations delivered to consumer projects continue in
[`.pbai4devs/scripts`](../kit/scripts/README.md), next to your resources.
Do not duplicate these tools in this directory.
