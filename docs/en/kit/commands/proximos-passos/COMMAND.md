# Next steps

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Use [Next steps](../../skills/projeto/proximos-passos/SKILL.md). With the CLI
available, use `agentdevkit next --target .` to consult the state. Choose
`--intent run` to run an existing project or `--intent product` to plan product
or functionality. Check the indicated skill and report the next action and the
pending that prevents it, when there is.
