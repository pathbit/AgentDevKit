# Documenting an existing system

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Receive the goal, repository and relevant streams or modules. Only clarify
questions that change the scope. Start with the local inventory with
`agentdevkit document --json` or by the draft output with `agentdevkit document
--markdown`.

Activate the [documenter][perfil] with [skill document-legate][skill]. Pass the
inventory and the existing documents. For a read request, return the survey and
its limitations in the response. When the request includes editing, complete the
authorized documents and check the links and evidence.

Give the responsible the draft survey, the flow references, the gaps and, if
there are changes, the diff and the evidence to [review-delivery][revisao].
