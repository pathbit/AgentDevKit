# Implement Delivery

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Entry: approved spec and plan, responsible and accept criteria. Check out the
prerequisites of
[implementation-spec](../../skills/specs/implementar-spec/SKILL.md). If approval
or definition is missing, return to
[plan-delivery](../planejar-entrega/COMMAND.md) for the first pending step.

Activate the [implementer](../../agents/implementador/AGENT.md) with the files
under your responsibility. It uses the skill, tests and tools of the project;
records remaining doubts before deciding requirements.

For independent tasks, distribute among available and authorised subagents, such
as [backend](../../agents/especialista-backend/AGENT.md) e
[frontend](../../agents/especialista-frontend/AGENT.md). Give each one context,
goal, dependencies, files unique to writing and expected proofs. The main agent
integrates the changes, resolves interfaces and confers the results. Unsupported
by the delegation, run in sequence and report this limitation.

Output: diff, criteria, execution commands, preliminary evidence and to-dos.
[validate-delivery](../validar-entrega/COMMAND.md). Failures return to the
implementer with the failed proof.
