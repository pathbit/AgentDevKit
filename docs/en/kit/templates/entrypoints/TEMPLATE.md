# Inputs of agents

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

The installer generates [AGENTS](AGENTS.md), [CLAUDE](CLAUDE.md) e
[GEMINI](GEMINI.md) as chosen customers. Human inputs are preserved; only old
blocks identified from the kit are migrated. The models point to the shared
source. The simulator uses these inputs to represent the actual installation.
