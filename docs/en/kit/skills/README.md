# Skills

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Choose the skill for the result you need. The font stays in
`<grupo>/<nome>/SKILL.md`. O [shared guide](../INSTRUCTIONS.md) shows the work
order and local catalog `../catalog.json` It brings together all the resources.

| I want to... | Where to start |
| --- | --- |
| Find out where the project is at | [Next steps](projeto/proximos-passos/SKILL.md) |
| Prepare a product or configure the approved technology | [configure-project](projeto/configurar-projeto/SKILL.md) |
| Rotate or repair an existing machine project | [prepare-dev](projeto/preparar-dev/SKILL.md) |
| Set product, experience or architecture | [create-prd](produto/criar-prd/SKILL.md), [create-ux-ui](produto/criar-ux-ui/SKILL.md) or [create-design-doc](produto/criar-design-doc/SKILL.md) |
| Specify an increment for approval or deliver an approved increment | [create-spec](specs/criar-spec/SKILL.md) or [implementation-spec](specs/implementar-spec/SKILL.md) |
| Choose test cases or prove a ready change | [plan-qa](qualidade/planejar-qa/SKILL.md) or [check-work](projeto/verificar-trabalho/SKILL.md) |
| Review diff or investigate a specific hypothesis of failure | [revision-code](qualidade/revisar-codigo/SKILL.md) or [validation-adversarial](qualidade/validar-adversarial/SKILL.md) |
| Diagnose security risks and prioritize corrections | [review-safe](seguranca/revisar-seguranca/SKILL.md) |
| Check access, map threats or correct a find | [review-authorisation](seguranca/revisar-autorizacao/SKILL.md), [Moulding and moulding](seguranca/modelar-ameacas/SKILL.md) or [correct-vulnerability](seguranca/corrigir-vulnerabilidade/SKILL.md) |

For specific tasks, see also the skills of `git`,
[backend](desenvolvimento/implementar-backend/SKILL.md),
[frontend](desenvolvimento/implementar-frontend/SKILL.md),
[architecture](arquitetura/avaliar-arquitetura/SKILL.md) e
[performance](qualidade/avaliar-performance/SKILL.md).

Use `criar-skill` when a recurring task needs its own decisions. To create
another type of resource, start with `criar-recurso`Keep essential instructions
in the file and optional details in references. Use `usar-skills-externas` for
cured references, `atualizar-documentacao` to keep the documents and
`revisar-entrega` to complete implementations.

Security skills are part of the kit installation. Scanners require [explicit
preparation](../commands/preparar-seguranca/COMMAND.md). When changing
inventory, sync local indexes and notes.
