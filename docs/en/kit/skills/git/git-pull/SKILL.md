# git-pull

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Go on. `.pbai4devs/rules/git/RULE.md`. Check branch, upstream, local changes and
divergence; search and integrate the remote without discarding work or rewriting
history. If a merge commit is required, check first the effective identities. If
there is conflict, preserve the state and resolve it only within the authorized
scope.

To integrate a revised implementation, follow [git-merge](../git-merge/SKILL.md)
with the proof of the original commit.

Check out the result of each query and report limitations. For example, an
inaccessible global ignore may affect the listing of untraceable files.
