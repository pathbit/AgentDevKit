# git status

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Show branch, prepared and unprepared changes, untraceable files and upstream
divergence. Use `GIT_OPTIONAL_LOCKS=0` in the queries, without assuming that
this ensures the exact preservation of the bytes of the index. If required, use
only one proven safe method for the repository or report the limitation.
