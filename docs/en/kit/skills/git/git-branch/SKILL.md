# git-branch

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Check out current branch, worktrees and local changes. Create or change the
requested branch preserving local changes. When the operation belongs to a spec,
follow [implementation-spec](../../specs/implementar-spec/SKILL.md) and choose
the base according to the flow of the project.
