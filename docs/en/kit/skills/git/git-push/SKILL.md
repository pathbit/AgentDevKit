# git-push

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Check branch, upstream, commits to be published, identities and messages, in
addition to checks. Send only complete and verified tasks, respecting
`.pbai4devs/rules/git/RULE.md` and remote protections. If there is authorship,
co-authorship or agent identification, inform and do not publish these commits.
Do not use forced push; if there is divergence or error, inform and preserve the
work.
