# Implement Frontend

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

In task covered by a spec, follow the prerequisites, plan and gate configuration
of [implementation-spec](../../specs/implementar-spec/SKILL.md), even for point
corrections. In single-handed correction, follow the scope, decisions and
existing components. `preparar-dev` If you need the environment.

Enlighten behavior, content and accessibility as per scope. Consider loading,
void, error and success, accessible semantics, keyboard and screen sizes.
Preserve backend contracts and protect data and secrets.

Use [check-work](../../projeto/verificar-trabalho/SKILL.md) to test the actual
interface in browser, desktop and mobile when applicable. Check flow, keyboard,
console and network. Combine automatic tests and keyboard inspection for
accessibility. Register evidence and pending coverage.
