# Prepare Tools

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Identify operation and selection in [tool catalog][catalogo]Reuse. Node.js 24+
and check out the npm. No compatible runtime, follow the
[bootstrap][bootstrap]The bootstrap of `instalar-ferramentas` flame `setup`
once. To consult or execute a tool, prepare only runtime when necessary and
resume the original operation.

No [manager][script], use `setup <seleção>` to prepare and verify, `install
<nome>` or `update <nome>` to change an installation, and `info`, `check` or
`run <nome> [argumentos]` to use what exists. See [installation
command][instalar] to choose the initial selection.

Check out the platforms in `TOOL.json`. The npm update uses the official record.
Native scanners follow the revised catalog pins. For security, use [Preparing
for safety][seguranca] to distinguish the CLI, the base and offline execution.
In browser, desktop, proxy or recording, see the tool guide and check
dependencies and permissions according to actual flow.

Report versions, results, and non-applicable items. Healthy previous
installations are reused or preserved in failure. A probe proves the executable
scan. Use [check-work][verificar] to prove operation in case of use.
