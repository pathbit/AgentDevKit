# Local execution

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

In security streams, use open source tools that run locally, without account,
paid license or mandatory remote service. Downloading binaries and public bases
is an explicit preparation; parsing code is a separate operation.

Do not send sources, inventories or credentials to scanner APIs. Disable remote
telemetry and queries by documented mode. If a tool or base is missing, record
the to-do; do not silently exchange for a cloud analysis.

Restrict tests to the authorized design and environment. Preserve settings,
human content and customer limits. Reports hide secrets and stay in
`.agent-tests/`; binaries and caches stay in the ignored local folders.
cliente/modelo AI has its own data policy: keep secret values out of context and
use references written in the conversation.
