# Delivery documentation

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Before you create, organize or change documentation, use
`atualizar-documentacao`: inventory and read what already exists. Reuse paths
and formats; complement gaps without deleting, moving or replacing files with
templates. In existing agent instructions, only add the reference to the kit;
preserve text, human names and metadata, including name collisions.

After implementing, follow `atualizar-documentacao` and the command
`revisar-entrega` before commit or merge. Use the models of the current phase;
record decisions without impact with justification and solve the findings of the
independent review. A change without spec also needs verifiable criteria and
evidence; this does not waive the prerequisites to implement functionalities.
