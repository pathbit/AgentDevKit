# Automaciones del repositorio

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Utilice las órdenes npm de la raíz. [release](release/README.md) contiene
verificación, empaquetado y publicación del producto. `npm run verify` ejecuta
el perfil completo; `npm run build` genera el tarball local, sin publicar.

Las automaciones entregadas a los proyectos consumidores continúan en
[`.pbai4devs/scripts`](../kit/scripts/README.md), junto a sus recursos.
No duplique estas herramientas en este directorio.
