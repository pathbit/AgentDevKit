# Estado

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

`agentdevkit.json` e `derived.json` registran selección, propiedad y archivos
generados en esta máquina. Son locales y ignorados; no los edite manualmente.

Las decisiones de producto `configuracao/ESTADO.md`, cuando se crean por el
flujo del proyecto, son fuentes compartidas y pueden ser versionadas. Comience
por [modelo de configuración](../templates/configuracao/TEMPLATE.md).
