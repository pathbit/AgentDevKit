# Entradas de los agentes

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

El instalador genera [AGENTS](AGENTS.md), [CLAUDE](CLAUDE.md) e
[GEMINI](GEMINI.md) Según los clientes seleccionados, las entradas humanas se
conservan; solo se migran bloques antiguos identificados del kit. Los modelos
apuntan a la fuente compartida. El simulador usa estas entradas para representar
la instalación real.
