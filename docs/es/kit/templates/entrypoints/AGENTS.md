# Instrucciones para agentes

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

El origen compartido es `.pbai4devs` (PathBit AI For Devs). Lea
`.pbai4devs/INSTRUCTIONS.md` para el orden de trabajo y los requisitos previos.

Skills: `.pbai4devs/skills/README.md`. Comandos:
`.pbai4devs/commands/README.md`Reglas: `.pbai4devs/rules/README.md`. Perfis:
`.pbai4devs/agents/README.md`. El inventario completo está en
`.pbai4devs/catalog.json` y los formatos de cada cliente en
`.pbai4devs/COMPATIBILIDADE.md`.

Use el `README.md` del proyecto para su contexto. Los clientes elegidos tienen
apuntamientos; scripts, herramientas y modelos permanecen en el origen
compartido. Respeta la selección en `.pbai4devs/state/agentdevkit.json`. Para
detenerla, use `agents` la CLI; no deduce al agente activo por la aplicación o
por las carpetas.
