# Siguientes pasos

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Concluya respuestas sobre trabajo con resultado, pendencias y próxima acción
aplicable, usando el idioma elegido en el proyecto. No chat o tela, termine con
**[ Siguiente paso ]** e a ação/comando; use **[ Next step ]** en inglés o **[
Siguiente paso ]** en español. Use skill
[proximospasos](../../skills/projeto/proximos-passos/SKILL.md) Cuando necesite
determinar la fase o sus prerrequisitos. No repita las etapas terminadas ni
confunda la instalación de instrucciones con aprobación de producto o ejecución
de pruebas.
