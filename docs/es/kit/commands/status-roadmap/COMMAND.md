# Status de roadmap

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Entrada: ninguna. Prerrequisito: configuración con el camino del roadmap.

Use [administrar-roadmap](../../skills/specs/gerenciar-roadmap/SKILL.md) En modo
solamente lectura. Si falta planificación, informe la próxima etapa del flujo.
