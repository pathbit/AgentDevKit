# Preparación del desarrollo

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Entrada: objetivo o error observado, si hay. Prerrequisito: proyecto existente.

Empiece por [diagnóstico](../diagnosticar/COMMAND.md), o reutilize el inventario
si todavía representa el ambiente. Pase el resultado para [preparar
dev](../../skills/projeto/preparar-dev/SKILL.md). Reúna dudas antes de cambios y
use los scripts y herramientas indicados por skill.

Salida: entorno verificado, órdenes de ejecución, URL y pendencias; evidencia
local en `.agent-tests/`. No reinicie la planificación de producto.
