# Siguientes pasos

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Use [proximospasos](../../skills/projeto/proximos-passos/SKILL.md). Con la CLI
disponible, use `agentdevkit next --target .` Para consultar el estado. Elija
`--intent run` para rotar un proyecto existente o `--intent product` Para
planificar producto o funcionalidad. Consulte la skill indicada e informe la
siguiente acción y la espera que la impida, cuando haya.
