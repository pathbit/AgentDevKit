# Prueba en el navegador

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Entrada: URL, acciones y resultado esperado. Prerrequisitos: aplicación
accesible, datos de prueba y herramienta de navegador disponible. Reúna lo que
falta.

Siga [verificar trabajo](../../skills/projeto/verificar-trabalho/SKILL.md) para
el flujo web. Utilice las pruebas del proyecto, agent-browser o el [executor
Playwright](../../scripts/testar-navegador/REFERENCE.md), según las herramientas
disponibles. El executor MCP No es un programa Node.

Salida: aserciones, console/rede, viewports y resultado por criterio; informes y
capturas en `.agent-tests/`. Fixtures de la infraestructura no prueban el
producto.
