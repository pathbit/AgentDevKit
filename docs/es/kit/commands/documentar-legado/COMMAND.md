# Documentar un sistema existente

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Recibir el objetivo, el repositorio y los flujos o módulos relevantes.
Esclarezca solamente dudas que cambien el alcance. Comience por el inventario
local con `agentdevkit document --json` o la salida de borrador con `agentdevkit
document --markdown`.

Acione el [documentador][perfil] con la [skill documentar-legado][skill]. Pase
el inventario y los documentos existentes. Para una solicitud de lectura,
devuelve el levantamiento y sus limitaciones en la respuesta. Cuando la
solicitud incluya edición, complete los documentos autorizados y compruebe los
enlaces y las evidencias.

Déle al responsable el levantamiento en borrador, las referencias por flujo, las
lagunas y, si hay cambios, diff y las pruebas para [revisar entrega][revisao].
