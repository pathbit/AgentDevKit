# git-push

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Echa un vistazo a branch, upstream, commits a publicar, identidades y mensajes,
además de las verificaciones. Envíe solamente tareas completas y verificadas,
respetando `.pbai4devs/rules/git/RULE.md` y las protecciones del remoto. Si hay
autoría, coautoría o identificación de agente, informe y no publique estos
commits. No use push forzado; si hay divergencia o error, informe y preserve el
trabajo.
