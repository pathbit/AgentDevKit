# git-pull

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Siga `.pbai4devs/rules/git/RULE.md`. Revise branch, upstream, alteraciones
locales y divergencias; busque e integre el remoto sin descartar trabajo o
reescribir histórico. Si es necesario un commit de merge, consulte antes las
identidades efectivas. Si hay conflicto, preserve el estado y lo resuelve solo
dentro del alcance autorizado.

Para integrar una implementación revisada, siga
[git-merge](../git-merge/SKILL.md) Así que, en el caso de la historia, la
evidencia del commit de origen.

Consulta el resultado de cada consulta e informe limitaciones. Por ejemplo, un
ignore global inaccesible puede afectar el listado de archivos no rastreados.
