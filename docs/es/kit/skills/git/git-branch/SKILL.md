# git-branch

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Echa un vistazo a branch actual, worktrees y cambios locales. Cree o troque la
branch solicitada preservando los cambios locales. Cuando la operación pertenece
a una spec, siga [implementar-spec](../../specs/implementar-spec/SKILL.md) y
elija la base conforme al flujo del proyecto.
