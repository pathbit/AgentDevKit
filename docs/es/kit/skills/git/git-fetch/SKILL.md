# git-fetch

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Consulte a remoto solicitado y busque sus referencias sin alterar archivos de
trabajo o integrar branches. Informe actualizaciones y divergencias relevantes;
no descarte cambios.
