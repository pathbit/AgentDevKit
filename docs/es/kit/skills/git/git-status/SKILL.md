# git-status

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Muestra branch, cambios preparados y no preparados, archivos no rastreados y
divergencias de upstream. Use `GIT_OPTIONAL_LOCKS=0` En las consultas, sin
suponer que esto garantice la preservación exacta de los bytes del índice. Si se
requiere, utilice sólo un método comprobadomente seguro para el repositorio o
informe a la limitación.
