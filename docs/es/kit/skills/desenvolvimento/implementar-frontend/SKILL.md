# Implementar frontend

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

En tarea cubierta por una spec, siga los prerrequisitos, el plan y el gate de
configuración de [implementar-spec](../../specs/implementar-spec/SKILL.md),
incluso para correcciones puntuales. En corrección avulsa autorizada, siga el
alcance, las decisiones y los componentes existentes. Acione `preparar-dev` Si
necesita el medio ambiente.

Esclarezca comportamiento, contenido y accesibilidad según el alcance. Considere
la carga, el vacío, el error y el éxito, la semántica accesible, el teclado y
los tamaños de pantalla. Preserve contratos con el backend y proteja datos y
secretos.

Use [verificar trabajo](../../projeto/verificar-trabalho/SKILL.md) Para probar
la interfaz real en navegador, escritorio y celular cuando sea aplicable.
Consulte flujo, teclado, consola y red. Combine pruebas automáticas e inspección
por teclado para accesibilidad. Regístrando evidencias y cobertura pendiente.
