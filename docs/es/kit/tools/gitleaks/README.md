# gitleaks

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Busca secretos en archivos y en historico Git.

Versao revisada: **8.30.1**. Licenca:
[MIT](https://github.com/gitleaks/gitleaks/blob/v8.30.1/LICENSE). Descargas
viene de [release
oficial](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1); cada
plataforma tiene SHA-256 fijado en `TOOL.json`.

`SCRIPT.mjs install` baja y verifica el ejecutable. `update` aplica la revisión
del catalogo; nao selecciona `latest` Sin revisarlo. `check` verifica integridad
y versao sin red; `run` preserva argumentos y código de salida. Use `node
.pbai4devs/tools/gitleaks/SCRIPT.mjs <acao>`.

Utilice las órdenes de desconcercación del kit para obtener salida redactada.
Resultados requieren triaje; revocar credenciales reales sigue siendo necesario.

Binarios, cachés y resultados se encuentran locales e ignorados. O CLI No
requiere cuenta ni pago. Consulte
[administrador](../../scripts/preparar-ferramentas/README.md).
