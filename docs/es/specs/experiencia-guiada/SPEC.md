# Experiencia guiada en la terminal

[Português (Brasil)][reading-pt] · [English][reading-en] · [Español][reading-es]

Al adoptar el kit, el equipo necesita saber qué verificar y qué recurso usar a
seguir. En un proyecto existente, ella también necesita aprovechar los
documentos que ya orientan el trabajo.

## Criterios de aceptación

- **AC-001** A CLI Encadena instalación, diagnóstico, verificación de la
  sincronización y orientación. Divergencias permiten revisar el plan antes de
  aplicar. La intención de ejecutar una aplicación mantiene el foco en el
  entorno.
- **AC-002** La consulta opcional de integraciones funciona antes y después de
  la instalación. Muestra caminos reconocidos y orienta su uso sin leer el
  contenido de los artefactos, seguir enlaces simbólicos o ejecutarlos.
- **AC-003** O README distribuido por npm y la guía en GitHub describen cuando
  adopta el kit, como comenzar y cuando consulta a BMad, OpenSpec, GitHub Spec
  Kit, Tech Leads Club o Dotcontext.
- **AC-004** El paquete pasa por las matrices de compatibilidad y actualización.
  La validación en una copia de Talquee compara archivos propios e índice Git.
